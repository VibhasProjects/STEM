Featured Project

Character Acceleration System

A experiment focused on movement, acceleration, scripting, and testing.

Roblox Studio Lua Game Development Movement System Documentation

Project Goal

The main idea for this project was to create an acceleration system and integrate it into one of my main projects that I am currently working on.

What I Built

I made and tested a movement system that uses the character and gradually multiplies its speed over time. To test the system, I used a coding studio throughout the development process and used the Developer Portal and other online resources to help find solutions to problems I encountered.

Development Process

First, I started with a plan for what I was actually going to make. I then took time to learn anything I might have been missing and make sure I would not run into major problems during development. After building the system, I tested it and confirmed that it worked smoothly while recording the entire process.

What I Learned

Through this project, I learned much more about Lua coding, debugging, and using online resources and other people's advice to help solve problems on my own. I also learned more about video editing and recording while documenting the development process.

Documentation Process

To successfully document the project, I had to learn more about recording software and how to connect the different parts of the project together. I also learned how to edit videos and gained more experience with video embedding while creating the final documentation.
